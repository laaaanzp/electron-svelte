# sv

An electron application with SvelteKit that uses folder-based routing.

## Creating a project

Clone this project first and install the node modules.

```sh
# install node modules
npm install
```

## Developing

Once you've created a project and installed dependencies with `npm install` (or `pnpm install` or `yarn`), start a development server:

```sh
npm run dev
```

## Building

To create a production version of your app:

```sh
npm run package 
```
